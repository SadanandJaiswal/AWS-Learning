# AWS

### What is AWS? 
Amazon Web Services (AWS) is a cloud computing platform provided by Amazon that allows individuals and businesses to access IT resources like servers, storage, and databases over the internet. Instead of buying and maintaining physical hardware, you can "rent" these resources on-demand and only pay for what you use.

Offering 200+ service, started with S3 (storage), EC2 (Computing power), RDS (database), Lambda (Serverless Computing)

## What makes AWS Special?

### 1. Pay Only for What You Use 
- No need to buy expensive servers.
- You pay only for the resources you use.
- **Example:** If you use a server for 5 hours, you pay only for those 5 hours.

### 2. Scale Easily 
- Increase or decrease resources whenever needed.
- **Example:** During a festival sale, an online shopping website can add more servers to handle extra users.

### 3. High Availability 
- AWS has data centers around the world.
- If one data center has an issue, another can continue providing the service.

### 4. Strong Security 
- AWS provides encryption, firewalls, identity management, and many security features to protect data.

### 5. Large Number of Services 
AWS offers 200+ cloud services, including:
- **EC2** – Virtual servers
- **S3** – Cloud storage
- **RDS** – Databases
- **Lambda** – Serverless computing
- **CloudWatch** – Monitoring

### 6. Trusted by Big Companies 
Many well-known companies use AWS, including:
- Netflix
- Airbnb
- Samsung
- Adobe
- NASA
