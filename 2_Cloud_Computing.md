# Cloud Computing

Cloud computing is the on-demand delivery of IT resources over the internet, where you pay only for what you use.

Access computing resources (like servers, storage, databases, and software) over the internet, rather than owning and maintaining physical hardware.

**Some of Cloud Service Providers**  :
- AWS
- Microsoft Azure
- GCP (Google Cloud Platform)
- Salesforce

### IaaS 
IaaS Provides virtualized computing resources such as servers, storage, and networking over the internet. You manage the OS, middleware, and applications, while the provider handles the physical infrastructure. This model is ideal for businesses needing full control over their environment with on-demand scalability. 

Example providers: AWS EC2, Google Compute Engine, Microsoft Azure VMs.

### PaaS
PaaS Provides a platform for developing, testing, and deploying applications without managing the underlying infrastructure. Developers focus solely on coding and managing applications, while the provider manages the platform. 

Example providers: Google App Engine, AWS Elastic Beanstalk, IBM Cloud Foundry.

### SaaS
SaaS Delivers software applications over the internet, allowing users to access them through a web browser without installation. The provider manages everything—hardware, software, updates, and security—while users simply consume the service. 

Example providers: Google Workspace, Salesforce, Microsoft 365, Zoom.



## Different Types of Cloud Deployments

### 1. Public Cloud
- Cloud services are available to **everyone** over the internet.
- It is owned and managed by a cloud provider.
- **Example:** Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP).

### 2. Private Cloud
- Cloud infrastructure is used by **only one organization**.
- It provides better security and control.
- **Example:** A bank or hospital using its own private cloud to store sensitive customer data.

### 3. Hybrid Cloud
- A combination of **Public Cloud + Private Cloud**.
- Organizations keep sensitive data in the private cloud and use the public cloud for other work.
- **Example:** A company stores employee records in a private cloud but hosts its website on AWS.

### Easy Way to Remember

- 🌐 **Public Cloud** → Shared by everyone.
- 🔒 **Private Cloud** → Used by one organization only.
- 🔄 **Hybrid Cloud** → Mix of Public + Private Cloud.
